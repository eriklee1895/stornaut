# Lean Pull-Request CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce the ordinary Stornaut pull-request gate to one approximately three-minute macOS job without dropping any current non-benchmark SwiftPM test or non-golden App contract.

**Architecture:** Keep `scripts/verify --headless` as the single public CI entrypoint, but make it an incremental seven-step contract. Let `swift test` own Swift package compilation and `xcodebuild test` own Debug App compilation; keep standalone bundle/signing, Debug/Release fixture leakage, UI, visual, and performance evidence in `scripts/verify --full`.

**Tech Stack:** zsh verifier scripts, Swift Package Manager/Swift Testing, Xcode 26.6/XCTest, GitHub Actions on `macos-26` arm64, Markdown ADR and agent documentation.

## Global Constraints

- Keep one GitHub-hosted macOS 26 arm64 job on `pull_request`, pushes to `main`, and `workflow_dispatch`.
- Keep the job read-only and invoke only `scripts/verify --headless` as its project gate.
- Preserve every current non-benchmark SwiftPM test and every current non-golden App contract; design-time counts are 330 and 106 respectively, not permanent caps.
- Preserve source boundaries, localization, verifier contract, documentation/diff, and rule-compiler checks in headless CI.
- Keep `scripts/verify --full` and bare `scripts/verify` as the canonical local completion gate.
- Do not add caches, path filtering, retries, sharding, parallel macOS jobs, coverage policy, or branch protection in this slice.
- Do not add XCUITest, golden snapshots, Peekaboo/TCC, Automation Mode readiness, benchmarks, Release products, or standalone bundle/signing claims to ordinary CI.
- Treat approximately three minutes as an observed hosted performance objective, not a pass/fail timing assertion.
- Do not weaken tests or increase tolerances to meet the timing objective.
